# 小学口算题目生成器

使用标准 C11，无第三方依赖。

## 编译与运行

在当前目录执行（只编译这个程序）：

```sh
gcc -std=c11 -O2 -Wall -Wextra -Wpedantic mentalmathgen.c -o mentalmathgen
./mentalmathgen --count 20 --numbers 3 --mul-div 1 --brackets 1 --min 1 --max 20
```

Windows 在 Visual Studio 开发者命令提示符中执行：

```bat
cl /nologo /std:c11 /W4 /utf-8 mentalmathgen.c /Fe:mentalmathgen.exe
mentalmathgen.exe --count 20 --numbers 2 --mul-div 1 --remainder 1 --answers 1
```

## 配置

布尔选项使用 `0`（关闭）或 `1`（开启）。未指定的选项使用默认值。

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `--count` | 20 | 题目数量，1～10000 |
| `--numbers` | 2 | 每题数字个数，2～16 |
| `--mul-div` | 0 | 是否允许乘除法；开启后仍包含加减法 |
| `--brackets` | 0 | 是否使用运算括号；两个数字时忽略 |
| `--min` / `--max` | 0 / 20 | 题面数字的闭区间范围，均为 0～1000000，最小值不大于最大值 |
| `--negative` | 0 | 是否允许加减产生负数；关闭时所有中间结果和最终结果均非负 |
| `--remainder` | 0 | 两个数字的除法是否允许余数；多于两个数字时忽略 |
| `--fractions` | 0 | 多于两个数字时，除法是否允许产生分数；两个数字时忽略 |
| `--spacing` | 0 | 相邻题目之间的空行数，0～100 |
| `--answers` | 0 | 是否在所有题目之后单独打印答案区，按题号对应 |
| `--seed` | 当前时间 | 固定随机种子，1～2147483647，用于复现 |
| `--help` | — | 打印帮助 |

题目统一以 `= ________` 留空。开启 `--answers 1` 时，在所有题目之后空一行输出 `Answers:` 答案区，答案按原题号排列。题面使用 `*` 和 `/` 表示乘除法。无括号时遵循先乘除后加减、同级从左到右的规则。有括号且超过两个数字时，生成随机二叉表达式并显示内部子表达式的括号。数字个数只统计题面操作数，不包括答案。

两个数字的带余除法答案用 `商...余数` 表示，例如题目 `7 / 3 = ________` 对应答案 `2...1`；多数字表达式中的分数采用精确有理数计算，答案约分输出，例如 `7/3`。不允许分数时，每次除法都必须整除，即使最终结果可能为整数，也不会接受中途产生分数的题目。除数可以是子表达式，其值绝不会为零。

去重按题面表达式文本判断：同一表达式不会重复；交换操作数、不同括号形式或相同答案的不同表达式仍算不同题目。哈希表处理哈希冲突时会比较完整文本。

生成采用随机候选与约束筛选。达到尝试上限（`题目数量 × 2000 + 10000`）仍不足时，向标准错误输出实际生成数量并返回失败，不输出不完整试卷；这并不证明数学上不存在足够题目。可增大范围、放宽限制或减少数量。为保证整数运算安全，每一步约分后的分子绝对值和分母不超过 10 亿，超出时舍弃该候选。

```sh
# 非负、整除的四数字混合运算，题间空一行
./mentalmathgen --count 30 --numbers 4 --mul-div 1 --brackets 1 --min 1 --max 10 --spacing 1

# 允许负数及中途分数，并打印答案；固定种子可复现
./mentalmathgen --count 20 --numbers 3 --mul-div 1 --negative 1 --fractions 1 --answers 1 --seed 42

# 重定向保存试卷
./mentalmathgen --count 50 > questions.txt
```

退出码：`0` 成功，`1` 生成、内存或输出失败，`2` 参数错误。

## 扩展位置

配置及参数校验集中在 `Config`、`parse` 中；运算符与优先级集中在 `operators`，精确计算与结果约束在 `calculate`；`tree`、`flat` 分别负责带括号和普通优先级表达式；`render` 负责题面，`main` 负责去重和打印。新增运算符时同步扩展运算符表、计算规则和候选选择范围，保留精确计算的溢出边界；新的输出格式可复用已经生成的 `Question` 数组。
