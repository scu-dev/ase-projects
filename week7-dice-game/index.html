    密码学安全随机数 / 了解随机来源

    每局通过 Web Crypto API 的 crypto.getRandomValues() 获取随机数。这是普通网页可直接使用的密码学安全随机接口，通常由操作系统熵源播种的密码学伪随机生成器提供。网页无法直接指定或验证硬件真随机源。

    每个随机字节只接受 0–251，再等概率映射为 1–6；252–255 会被丢弃并重新取数，避免取模偏差。两颗骰子分别取样，动画不参与结果计算。安全随机接口不可用时停止投掷。查看 Web Crypto 规范 ↗
