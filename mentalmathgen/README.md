# MentalMathGen

小学口算题目生成器。沿用 `week3-mentalmathgen` 的题目规则，以 Python 3.12、Tkinter 和 ttk 实现本地 GUI，界面结构参考 `codecounter`。生成、去重和精确计算均在 Python 中完成，不调用 C 程序。

## 运行

在当前目录执行：

```powershell
uv run main.py
```

需要包含 Tcl/Tk 的 Python 解释器。项目依赖 ReportLab，用于导出 PDF；`uv run` 会按锁文件安装依赖。已初始化虚拟环境时也可以运行：

```powershell
.\.venv\Scripts\python.exe main.py
```

## 使用

1. 在左侧设置题目数量。点击“每题数字个数”或“数值范围”旁的范围按钮，展开后拖动双滑块或输入上下限，再选择运算规则。一次展开一组范围，两个滑块可以重合。
2. 每次点击“生成题目”都会随机出一份试卷。生成期间可以取消。
3. 在右侧“题目”和“答案”页签切换预览。
4. 点击“题目 TXT”“答案 TXT”“题目 PDF”或“答案 PDF”，分别选择保存位置。

四种导出始终使用当前同一份试卷，不会重新随机生成，题号与答案一一对应。生成、完成和错误等状态显示在“生成题目 / 取消”按钮组下方。修改生成参数后，上一份试卷仍可预览和导出，状态文字会提示需要重新生成。只有成功生成完整试卷才会替换旧结果；失败或取消会保留上一份试卷。

## 生成规则

| 设置 | 默认值 | 范围与含义 |
| --- | --- | --- |
| 题目数量 | 20 | 1～10000 |
| 每题最小数字个数 | 2 | 2～16，仅统计题面操作数 |
| 每题最大数字个数 | 2 | 2～16，不能低于每题最小数字个数 |
| 最小 / 最大数值 | 0 / 20 | 0～100 的闭区间，只限制题面数字，不限制答案 |
| 允许乘除法 | 关闭 | 开启后包含加、减、乘、除，不保证每份试卷的运算符比例 |
| 使用括号 | 关闭 | 超过两个数字时启用，生成随机二叉表达式，内部子表达式显示括号 |
| 允许负数 | 关闭 | 关闭时所有中间结果与答案均非负；题面操作数始终非负 |
| 除法允许余数 | 关闭 | 仅两个数字且开启乘除法时有效，答案格式为 `商...余数`；整除时只显示商 |
| 除法允许分数 | 关闭 | 仅超过两个数字且开启乘除法时有效，答案以约分后的精确分数显示 |
| 题间空行 | 0 | 0～100；只影响题目预览、题目 TXT 和题目 PDF，不改变题目或答案 |

生成每个候选题时，从最小和最大数字个数的闭区间中随机选择个数；上下限相同时生成固定个数的题目。最终各个数的题目比例会受约束筛选和去重影响，不保证平均分配。

数字个数不会禁用任何复选框。括号、余数、分数规则按每道题的实际数字个数生效：两个数字时不加括号，除法按余数选项处理；超过两个数字时，按括号和分数选项处理。未开启乘除法时，余数和分数选项仍禁用并保留勾选状态。

界面与导出使用 `×`、`÷` 表示乘除。无括号时遵循先乘除后加减、同级从左到右。每一步运算均不允许加减 0、乘除 1，右侧子表达式计算结果为对应数值时也会过滤。关闭分数时，多数字题目的每次除法都必须整除，即使整个表达式的最终结果可能为整数，也不接受中间产生分数的题目。除数及作为除数的子表达式均不为零。

去重按完整题面文本判断。交换操作数、不同括号形式或相同答案的不同表达式仍算不同题目。分数采用 Python `Fraction` 精确计算，每一步约分后的分子绝对值与分母不超过 10 亿，超出时舍弃候选。

固定为两个数字且原始候选空间不超过 20000 时，枚举有效题目后无放回抽样，可以准确报告不足的数量。其他情况使用随机候选与约束筛选，尝试上限为 `题目数量 × 2000 + 10000`；达到上限时提示已找到数量，不返回不完整试卷，这不代表数学上不存在足够题目。较严格的规则可能耗时较长，可取消并调整参数。随机序列不与原 C 版保持一致。

## 导出格式

- **题目 TXT**：按题号排列，每题以 `= ________` 留空，保留设定的题间空行。
- **答案 TXT**：只含对应题号及答案，一行一题。
- **题目 PDF**：A4 纵向，含姓名与日期栏，长题目自动换行，整道题一起分页。
- **答案 PDF**：独立文档，按题号排列，仅显示答案。

TXT 使用 UTF-8、LF，末尾不额外加换行。PDF 页脚显示页码。题间空行超出当前页时直接进入下一页，不生成空白页。PDF 嵌入本机中文字体，Windows 优先使用宋体或黑体，macOS 尝试华文黑体，Linux 尝试文泉驿正黑；找不到受支持字体时会明确提示，不生成缺字文件。

生成和导出都在后台线程运行。保存先写入目标目录的临时文件，成功后替换目标；导出失败或取消不会覆盖原文件。窗口关闭时通知后台操作取消。

## 测试

```powershell
uv run python -m unittest discover -s tests -v
```

测试依赖组包含 `pypdf`，用于读取导出的 PDF。覆盖独立语法树验算、运算优先级、中间结果约束、分数与余数、去重容量、取消、参数校验、TXT 编码、PDF 分页与字体嵌入、四种 GUI 导出及状态恢复。GUI 测试需要可用的本地 Tk 窗口环境。测试不执行项目构建。

## 文件与扩展

- `generator.py`：配置、题目模型、精确运算、表达式生成及去重，可独立于 GUI 使用。
- `exporter.py`：题目 / 答案排版，以及 TXT、PDF 原子写入。
- `main.py`：Tkinter 界面、输入校验、后台任务和状态提示。
- `range_selector.py`：可折叠的双滑块范围控件与精确输入。
- `tests/`：生成逻辑、导出与 GUI 回归测试。
- `pyproject.toml`、`uv.lock`、`.python-version`：Python 版本、运行与测试依赖。

新增运算符时同步扩展 `OPERATORS`、`PRECEDENCE`、`_calculate` 与对应测试；新增导出格式可复用 `Worksheet`，无需重新生成题目。
